#Spectrum Analyzer

The digital products of the Axell Wireless product family contains an ADC/DAC and an FPGA where the incoming signal is
continuously captured.
By retrieving the data onto the controller and performing an FFT this allows for a spectrum analyse of the input of the
repeater, allowing to identify any disturbances or intermodulations that might corrupt the repeater performance.

##Control buttons

There is a set of buttons under the screen that allows interacting with the spectrum analyzer:

 * **Start, Stop, Center, Span:** These 4 buttons allow you to adjust the range for the signal
 * **Clear Peak Hold:** Clears the peak hold data (see below)
 * **Set Resolution:* Sets the sampling resolution for the data.
 * **Zoom in:** Zooms in +50% around the current center point
 * **Zoom out:** Zooms out -50% around the current center point
 * **Reset View:** Resets the view to show the whole range for the current link (uplink or downlink)
 * **Move Left:** Moves the diagram 10% to the left (which is equal to one grid line)
 * **Move Right:** Moves the diagram 10% to the right (which is equal to one grid line)
 * **Uplink:** Chooses to show the uplink
 * **Downlink:** Chooses to show downlink
 * **Save:** Captures an snapshot of the diagram and saves it as a PNG file.

##Peak Hold

The controller saves the highest level of the signal (peak) together with information about when it happened.

When hovering over the signal with your mouse, you can see the peak information behind the current signal value with a darker color. The date and time that is shown at the top of the cursor line is the moment that this signal has had its highest value. The value itself is shown along the line that has the same color as the peak diagram.

The *Clear Peak Hold Data* button allows you to clear this historical data. The data persist as long as the controller hasn't restarted or you manually haven't cleared it.

Using the *Save Peaks into a text file* you can save a copy of the peak hold data for future reference or print it.

##Raster Details

The raster is defined as the distance in Hz between each FFT bin centre.
The span for the FFT is 125 MHz, but only half of the FFT bins are used (0-62.5 MHz).
This means that half of the FFT bins are used of the samples requested in hardware.
