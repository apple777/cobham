Welcome to the COBHAM idDAS system!
Before the system can be used, the following steps are needed:
  1. One or more operators need to be added to the system. Please give each operator a short name to use in the system, and also a longer more user-friendly description.
  2. Each operator is given a default filter quota allocation (amount of DSP resources at each RRU and MTDI), which can be edited in advanced setting. The total available to be shared between operators is 64.
  3. Each operator is given a default CPRI (fibre link capacity) and RF Power quota allocation, which can be edited in advanced setting. Those are in % of total available link capacity and RF power.
All of the above are entered in this window. Once you have made these settings, you will be directed to the RF Settings page, where the operator frequency allocations within each RF band are defined. These are the frequency ranges that the operators are permitted to use according to their regulatory spectrum allocations.

Once these steps are done, each operator can begin to connect their base station Sectors and add the corresponding Cell Resources (carrier frequency ranges within each BTS port) from the main screen.
