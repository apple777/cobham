Common Features

Node Status

  • View the alarm status of a system node
  • View and edit the tag and location tag of a system node
  • View the nodes fibre optic status
  • View the system nodes power, temperature and fibre optic levels

Alarm Thresholds

  • View and edit the alarm thresholds

External Alarms

  • View and edit the external alarm descriptions
  • View and toggle external alarm active high / active low configuration

Communication

  • View and edit the configuration for communicating with external devices

SNMP

  • View and edit the configuration for communicating with an SNMP server

Active Alarms

  • View the list of recent alarms
  • Delete all the system alarms
  • Acknowlege all the system alarms

Quota Management

  • View and edit the amount of allocated filter bandwidth for different operators
  • Configure exceptions for allocated filter bandwidth
  • View and edit the amount of allocated CPRI capacity for different operators
  • Configure exceptions for allocated CPRI capacity

System Information

  • View the serial numbers and software versions of the device
  • View system diagnostic information such as cpu, ram and un allocated disk space.
